# Capture Colin / Capture Colin's Clones
`Capture Colin` is a small puzzle/game project created for a monthly newsletter inspired by Where's Wally.
Users accessing the puzzle site, attempt to locate and click on Colin to win.

## First Iteration (July)
- One `Colin` to find.
- Countdown timer (5mins max).
- Popup with confetti and congratulations.
- Timer stops when Colin is found; users were instructed to take a screenshot as proof.
- No logging of users, based on trust. (This was a mistake.)
- Reset functionality. (Another mistake.)
- If the mouse hovered over `Colin` it would give the game away. -.-
- Photo was shown before the game started. (Maybe we should stop counting the mistakes?)

## Second Iteration (August)
- Three `Colin Clones` to find.
- Art created with the help of figma inspired avatars, and own design with Procreate and Photoshop.
- Users must submit name and email to prevent (reduce) cheating.
- New logging facility to help weed out fake users that use alternative emails to game the system.
- Image is only displayed after the user clicks `Start Game`.
- Timer now counts up.
- Users only get one go... no refreshing allowed.
- Popup notifications to alert when a clone has been clicked.
- No mousing over to find Colin!
- If a user does try to reload the game and has already played, it will provide their previous time, and will not allow them to play again.
- Added reminder message in popup to take a screenshot.
